# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问`http://localhost:3025`。支持样本创建、切片任务、步骤记录和交付统计。

保存期与离库见证：

- 建档填写保存截止日、保管人；保存截止前 30 天自动进入「待复核」，过期标记「已到期」。
- 样本卡片直接显示剩余天数、阻断原因和最近处理；统计区单列待复核/到期与已销毁数量。
- 借阅登记/归还、合作方复检（开始/结束）均在卡片上操作并计入处理历史。
- 仍在借阅、切片未做完或有未结束复检的样本不能排入销毁；未进入待复核期的同样拦截。
- 销毁需两名不同见证人现场核对编号与方式，服务端记录时间并生成凭证；销毁后从可用样本和统计移出，原切片步骤与销毁凭证在「销毁凭证与存档」区仍可查（`GET /api/destroyed`）。
