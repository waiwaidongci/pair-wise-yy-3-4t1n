# 岩芯样本切片实验室

运行：

```bash
npm start
```

访问`http://localhost:3025`。支持样本创建、切片任务、步骤记录和交付统计。

## 保存期与离库见证

- 建档时登记保存截止日、保管人和复检状态；到期前 30 天自动进入“待复核”，逾期单独标记。卡片直接显示剩余天数、阻断原因和最近处理。
- 样本可登记借阅/归还，可开始/结束合作方复检。
- 离库见证台：仍在借阅、切片未完成或复检未结束的样本会被阻断，不能排入销毁；无阻断样本由两名见证人现场核对编号与销毁方式后销毁，系统留下销毁时间并出具凭证。
- 销毁档案：已销毁样本从可用样本与统计中移出，原切片步骤与销毁凭证仍可查询（`GET /api/archive`）。
